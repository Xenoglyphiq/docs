# Xenoglyphiq docs

Source for **[docs.xenoglyphiq.dev](https://docs.xenoglyphiq.dev)**: install instructions and examples for every Xenoglyphiq library, in every language it has a port for.

Built with [Astro Starlight](https://starlight.astro.build). Deployed to GitHub Pages on every push to `main`, and rebuilt daily so library data stays current.

## Develop

```
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```
